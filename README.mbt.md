# MoonLink

MoonLink 是一个面向 Windows 10/11 x64 的局域网远程协助项目。第一期使用两个免安装应用：被控端选择一个显示器并明确允许连接；控制端输入地址和一次性验证码后获取远程画面及鼠标键盘控制。

## 当前状态

纯 MoonBit 核心、值型原生 FFI、原生 C ABI 输入授权闸门，以及 Windows 原生可行性探针已通过自动化测试：桌面复制对象创建、D3D11 清屏呈现、软件/硬件 H.264 编码 MFT 激活、本机 WebRTC 控制通道和 H.264 轨道协商。

尚未实现连续桌面采集、720p H.264 帧编码与发送、远端解码和呈现、Windows 输入执行、Proton 两端界面或真实两机性能测量。不要将当前仓库视为可用远控工具。

## 固定边界

- 平台：Windows 10/11 x64。
- 网络：仅千兆有线局域网直连；不包含公网、STUN/TURN 或中继。
- 会话：被控端每次确认；地址加短时一次性验证码；无账号和无人值守。
- 功能：一个显示器、等比 1280×720 留边视频、鼠标键盘控制。
- 性能目标：硬件 H.264 可用时 60fps，视频 P95 不高于 150ms，控制 P95 不高于 80ms。
- 软件编码回退：720p 30fps，并明确报告降级状态。
- 不包含：音频、剪贴板、文件传输、自动更新、安装包和代码签名。

## 结构

- `core/`：纯 MoonBit 会话状态、授权、坐标映射、能力契约与技术轨迹。
- `apps/`：被控端和控制端的 MoonBit 应用组合层。
- `native/`：独立构建的 Windows 原生桥；只通过稳定 C ABI 连接 MoonBit。
- `docs/`：架构、FFI、威胁模型、测试和路线图。
